## 2026.0.15

### Added
- In the launcher, the Right arrow opens the selected app’s actions menu when the cursor is at the end of the search text. With text to the right of the cursor it moves the cursor as usual, and Tab still opens the menu.

### Changed
- Locus Launcher now has its own menu bar icon in place of the generic grid symbol.
- Settings, the setup checklist, Hidden Apps, and App Hot Keys window open centered the first time and remember where you left them after that.
- The hot key editor opens over whatever opened it — the launcher panel or the App Hot Keys window.
- The setup checklist row is gone from Settings. Setup Checklist in the menu bar menu still opens it.

### Fixed
- Manage Hot Keys now opens a window per app, so you can have editors open for several apps at once. Opening one for a second app used to take over the window already open and leave it the wrong size and in the wrong place. An editor that would land on one already open now steps down and to the right instead.
- Opening Settings no longer focuses the launcher shortcut field ready to record, which could replace your shortcut with the next keys you pressed.
