## 2026.0.9

### Added
- Settings now has an “Open at login” switch.
- Choose your own launcher shortcut in Settings.
- Spotlight uses Cmd + Space out of the box, which keeps the launcher from opening with it. Settings shows when Spotlight's shortcut is on and turns it off with one click. If Locus Launcher turned it off, Settings offers to turn it back on.
- If Spotlight is using the launcher's shortcut when Locus Launcher starts, it asks whether to turn Spotlight's shortcut off.
- Settings has switches for checking for updates automatically and for getting beta updates. Betas arrive more often and may break things.

### Changed
- When Locus Launcher finds an update on its own, it no longer pops up a window while you're working. Instead, a red dot appears on the menu bar icon, the menu gets an Install Update item, and an Update button appears next to the launcher's search field. Click either to see the update.
