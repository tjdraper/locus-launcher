## 2026.0.10

### Added
- The selected app in the launcher now has an actions menu. Press Tab or click the arrow at the end of the row to open it. Use the arrow keys and Return to pick an action, or Esc to close the menu without closing the launcher. The actions are Open (Return), New Window (Option + Cmd + Return), Reveal in Finder (Cmd + Return), and Hide from Launcher (Option + Cmd + Delete). Each shortcut also works in the launcher without opening the menu.
- New Window brings the app forward and opens a new window in it. It needs Accessibility access, which Locus Launcher asks for the first time you use it. Without access, New Window only brings the app forward. If the app isn't running yet, it just opens the app.
- Settings has a new Permissions section that shows whether Accessibility access is allowed, with a button to allow it.
- Hidden apps no longer appear in the launcher, in the list, or in search results.
- A new Hidden Apps window lists the apps you've hidden and lets you unhide them. Open it from the menu bar menu or with Control + Option + Cmd + H while the launcher is open. Each hidden app has a "Sync to other Macs" choice, which will take effect when syncing arrives in a later update.
