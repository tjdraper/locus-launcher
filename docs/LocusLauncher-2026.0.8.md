## 2026.0.8

### Added
- Type in the launcher to search your apps. You don't need to type the whole name: the letters you type just have to appear in order, so "saf" finds Safari and "vsc" finds Visual Studio Code. Case and accents don't matter. The best match is selected, so Return opens it right away. Clear the search to go back to the full list.
- The launcher remembers which app you open for what you typed and puts it first the next time. The first letters of that search count too, so opening Safari after typing "saf" also moves it up when you type "s". Recent choices count more than old ones, so the order follows your habits as they change. This history stays on your Mac.

### Fixed
- Safari and other apps that macOS keeps in a protected system folder no longer show a shortcut arrow on their icons.
