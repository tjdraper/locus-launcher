## 2026.0.13

### Added
- A setup checklist puts every setup step on one page: moving the app to `/Applications` if it’s not there, choosing the launcher shortcut (and turning off Spotlight’s if it’s in the way), allowing Accessibility access, opening at login, and checking for updates automatically. It opens on the first launch of a new install and comes back each launch until you click Done. Open it anytime from Setup Checklist in the menu bar menu or from Settings.

### Changed
- The checkmark next to Accessibility access in Settings is now green.

### Fixed
- Moving Locus Launcher to Applications now moves the old copy to the Trash instead of leaving it behind.
