## 2026.0.5

### Added
- Added a global hotkey, Cmd+Space, that opens and closes the launcher. Spotlight uses the same shortcut, so turn off Spotlight's in System Settings → Keyboard → Keyboard Shortcuts → Spotlight for now (an option is coming in a future beta to automatically take care of this conflict).
- The launcher opens on the screen the pointer is on, with the cursor in the search field. Searching for apps comes in a future beta. Press the hotkey again, use escape, or click outside the launcher to close the launcher.
- Added a Settings window. Open it with “Cmd + ,” while the launcher is active, from the menu bar menu, or by opening Locus Launcher again while it's running.

### Changed
- The launcher no longer opens when the app starts.
